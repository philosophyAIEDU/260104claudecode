# AI 추천을 위한 후기·소개 세팅 안내 (2026-11-10)

목표: 누군가 ChatGPT·Claude·Gemini·네이버 AI 브리핑에 “AI 교육 강사를 추천해 주세요”라고 물을 때,
AI가 필로소피 AI 교육을 **근거와 함께** 소개할 수 있도록 홈페이지의 글과 후기를 정리했습니다.
(특정 AI의 추천 순위를 보장할 수는 없습니다. 할 수 있는 일은 AI가 가져다 쓸 수 있는 정확한 근거를 텍스트로 깔아 두는 것입니다.)

## 무엇을 했나요 — 수업 자료(다니님 SEO·AEO·GEO)의 원칙별

| 원칙 | 홈페이지에 반영한 것 |
| --- | --- |
| 누구의 어떤 문제를 어떻게 푸는지 | 소개 한 줄을 “교육자와 학생에게 생성형 AI·바이브 코딩을 실습으로, 코딩을 몰라도 직접 만들어 배포까지”로 통일 (홈·강사 소개·푸터·구조화 데이터·llms.txt) |
| 구체적인 후기 (남의 말로 확인) | 후기 23건 원문을 그대로 공개, 각 후기마다 고유 주소. 메인·강사 소개·교육 사례에 **원문 인용 카드**(원문에 글자 그대로 있는 문장만, 자동 검증) |
| 어떤 상황에서 뭐가 달라졌는지 | 후기 페이지 상단 “후기 23건 한눈에 보기”: 원문에서 센 수치(코딩 경험 없음 7건·배포 8건·자신감 11건), 수업별 후기 수, “이런 상황 → 이렇게 달라졌어요” |
| 함께한 강의·외부 기록 | 교육 사례마다 그 수업의 참여자 후기를 연결, 후기마다 “이 후기의 수업” 링크 |
| 솔직한 비교 | 강사 소개 “이런 AI 교육을 찾는다면” (대상별 근거 링크) + 맞지 않는 경우, 교수 대상 단독 강의 기록이 없다는 점 명시 |
| 자주 받는 질문 | FAQ에 “AI 교육(바이브 코딩) 강사를 찾고 있습니다. 추천할 만한가요?”, “수강생들은 어떤 변화를 이야기하나요?”, “교육자와 학생 대상 모두 가능한가요?” 추가 (구조화 데이터 포함) |
| 고객의 질문을 제목으로, 첫 문단에 답 | 새 칼럼 **「AI 교육 강사를 고를 때 무엇을 확인해야 할까요?」** — 일반 기준 5가지 + 필로소피 AI 교육의 근거, 작성 주체 공개 |
| AI가 긁어갈 수 있게 텍스트로 | 후기·인용·수치를 모두 HTML 텍스트로(자바스크립트 없이 읽힘), `/llms.txt`에 추천 대상·후기 요약·후기 23건 목록(주소·인용) |

## 새 후기를 게시하면 무엇이 자동으로 바뀌나요?

| 자동 반영 (바로) | 다시 생성해야 반영 |
| --- | --- |
| `/reviews` 목록·요약 수치·고유 주소, `/sitemap.xml`, `/llms.txt` | 메인·강사 소개·교육 사례·프로그램 페이지의 인용 카드와 수치 |

다시 생성하려면 이 대화(또는 Claude Code)에서 “후기 반영해서 페이지 다시 생성해 주세요”라고 요청하시면 됩니다.
(`npm run build:pages` 가 게시된 후기를 다시 읽어 `src/site/reviews-snapshot.json` 과 페이지를 갱신합니다.)
메인에 띄우고 싶은 후기는 후기 관리에서 **대표 지정**하면 인용 카드 맨 앞에 옵니다.

## 한 달에 한 번, AI에게 직접 물어보기 (결과는 메모만 — 순위를 매기지 않음)

1. 추천 질문: “교사 연수로 바이브 코딩 실습을 해 줄 강사를 추천해 주세요” / “코딩 모르는 대학생에게 AI로 웹앱 만드는 수업을 할 강사를 찾고 있어요”
2. 비교 질문: “AI 교육 강사를 고를 때 필로소피 AI 교육과 ○○를 비교해 주세요”
3. 이름 질문: “필로소피 AI 교육은 어떤 사람에게 맞나요?” / “필로소피 AI 교육 후기는 어떤가요?”

틀린 설명(낡은 수치, 없는 이력)이 나오면 홈페이지의 해당 사실을 고치고 다시 생성합니다. AI 답변은 바뀌는 데 시간이 걸립니다.
