# 후기 간편 등록 · 네이버 카페 후기 이전 가이드 (운영자용)

관리자 화면: **https://philosophyaiedu.com/reviews-admin.html**
(관리자 대시보드 → ‘후기 관리’ → **후기 간편 등록**, 또는 메인 페이지 관리자 영역의 ‘후기 간편 등록’ 버튼)

기존 관리자 계정(`warmcomfortforyou@gmail.com`, Google 로그인)으로만 열립니다. 새 로그인 체계는 없습니다.

## 1. 한 건씩 옮기기 — 카페 후기 복사 → 붙여넣기 → AI 정리 → 확인 → 게시

1. **공개 동의 받기** — 작성자에게 홈페이지 게시 동의를 받습니다. ‘후기 요청 가이드’ 탭의 문구를 복사해 카페 쪽지·댓글로 보내면 됩니다.
   이름 표시 방식(실명/닉네임/익명)과 소속 기관명 공개 여부도 함께 확인합니다.
2. **원문 붙여넣기** — 카페 글 본문을 드래그해 복사(Ctrl+C) → ‘후기 원문’ 칸에 붙여넣기(Ctrl+V).
   줄바꿈·문단은 그대로 유지됩니다. 원문은 오탈자도 고치지 않습니다(필요하면 작성자와 상의 후 ○○ 처리).
3. **원본 URL** — 카페 글 주소를 붙여넣습니다. 이미 등록된 주소면 ‘중복 등록 의심’ 경고가 뜹니다.
4. **작성자 · 작성일 · 프로그램** — 이름 표시/익명, 작성자 유형, 원본 게시일, 교육 프로그램, 분류를 고릅니다.
5. **이미지** — 사진이 함께 복사되면 자동으로 들어옵니다. 들어오지 않으면(카페 이미지는 외부 접근이 막혀 있음) 사진을 PC에 저장한 뒤
   ‘이미지 첨부’ 상자에 끌어놓거나 파일로 올립니다. 화면 캡처는 상자를 누른 뒤 Ctrl+V. ↑↓로 순서 변경, ✕로 삭제.
   업로드 전에 자동으로 크기를 줄이고 위치정보(EXIF)를 지웁니다. 얼굴·이름표·학생 정보가 보이면 가린 뒤 올려 주세요.
6. **AI로 후기 정리하기** — 제목, 교육 전 고민, 인상 깊었던 실습, 교육 후 변화, 요약, 프로그램·분류가 채워집니다.
   - 오른쪽 ‘원문과 비교하기’에 AI가 근거로 든 문장이 노란색으로 표시됩니다.
   - 원문에 근거가 없는 항목은 **‘언급 없음’** 으로 남고 홈페이지에 표시되지 않습니다.
   - AI 결과는 자동으로 저장·게시되지 않습니다. 반드시 읽고 고쳐 주세요.
7. **공개 동의 확인** — ‘작성자 공개 동의’를 **공개 동의를 확인함**으로 바꾸고, ‘동의 확인 기록’에 날짜와 방법을 적습니다.
   (동의 전에는 버튼을 눌러도 게시되지 않습니다 — 서버 보안 규칙에서도 막혀 있습니다.)
8. **미리보기** → **홈페이지에 게시하기**. 게시 주소(`/reviews/고유주소`)가 표시됩니다. 캐시 때문에 반영까지 최대 5분 걸릴 수 있습니다.

| 버튼 | 동작 |
| --- | --- |
| 임시 저장 | 홈페이지에 표시하지 않고 저장 (게시된 후기에 누르면 확인 후 내려감) |
| 홈페이지에 게시하기 | 동의 확인·필수 항목 점검 후 게시. 게시된 후기를 고친 뒤 누르면 수정 반영 |
| 게시 상태 = 비공개 + 임시 저장 | 비공개로 저장 |
| 대표 후기로 지정 | 게시된 대표 후기 중 최대 6개가 메인 페이지에 노출 (3~6개 권장) |

### 비공개로 저장되는 정보
실명, 연락처, 원래 소속 기관명(공개 허가가 없을 때), 동의 확인 기록, 운영 메모, AI 정리 원본 결과는
`review_private` 컬렉션에 따로 저장되어 **관리자만** 볼 수 있습니다. 공개 후기 문서에는 들어가지 않습니다.

## 2. 여러 건 한 번에 — CSV / JSON 가져오기

‘일괄 가져오기 · 내보내기’ 탭 → ‘CSV 서식 내려받기’로 서식을 받아 채웁니다.

| 열 | 필수 | 예 |
| --- | --- | --- |
| 원문 (originalText) | ✔ | 여러 줄이면 큰따옴표로 감싸기 |
| 원본 URL (sourceUrl) |  | https://cafe.naver.com/PHILOSOPHYai/123 |
| 작성일 (reviewDate) |  | 2026-06-05, 2026.6.5, 20260605 |
| 작성자 (authorDisplay) |  | 익명 / 김○○ 선생님 |
| 교육 프로그램 (program) |  | AI 리터러시, 바이브 코딩, 업무 자동화, 교수자 … |

가져온 후기는 모두 **임시저장 · 동의 확인 전** 상태입니다. ‘후기 목록’에서 하나씩 열어 AI 정리 → 동의 확인 → 게시합니다.
중복(같은 URL·비슷한 원문)으로 보이는 행은 체크가 해제된 채로 표시됩니다.

**기존 ‘강연 후기’ 게시판 글**은 같은 탭의 ‘강연 후기 불러오기’로 임시저장 복사본을 만들 수 있습니다(원래 게시판 글은 그대로 남습니다).
게시판 등록일은 원본 후기 작성일과 다를 수 있으므로 작성일은 비워 두었습니다 — 원본을 확인해 입력해 주세요.

## 3. 백업
‘JSON 내보내기 / CSV 내보내기’로 전체 후기를 내려받을 수 있습니다. ‘비공개 정보 포함’을 체크하면 실명·연락처도 JSON에 들어가니 안전하게 보관하세요.

## 4. 처음 한 번 해야 하는 설정 (운영자 · 배포 담당)

1. **Firestore 규칙 배포** — `firebase deploy --only firestore:rules` (reviews / review_private 규칙 추가됨)
2. **Firebase Storage 시작 + 규칙 배포** — Firebase 콘솔 → Storage → 시작하기, 그다음 `firebase deploy --only storage`
   (Storage를 켜기 전에는 이미지 업로드만 실패하고, 텍스트 후기 등록·게시는 정상 동작합니다)
3. **AI 정리 기능 (선택)** — Netlify → Site settings → Environment variables
   - `ANTHROPIC_API_KEY` : Anthropic API 키 (필수, 브라우저로 내려가지 않음)
   - `ANTHROPIC_MODEL` : 선택, 기본 `claude-opus-5-5`
   - `ADMIN_EMAIL` : 선택, 기본 `warmcomfortforyou@gmail.com` (firestore.rules의 관리자와 같아야 함)
   키가 없으면 ‘AI 정리 기능이 설정되지 않았습니다’ 안내가 뜨고, 직접 입력해 게시할 수 있습니다.
   AI 호출은 거절(refusal) 시 서버 측 대체 모델(`fallbacks: "default"`)로 다시 시도하도록 설정되어 있습니다.
4. 관리자 이메일을 바꾸려면 `firestore.rules`, `storage.rules`, `reviews-admin.html`, `admin-dashboard.html`, Netlify `ADMIN_EMAIL`을 함께 바꿉니다.

## 5. 후기 신뢰성 원칙 (화면과 서버에서 강제되는 것)
- 존재하지 않는 후기·결과를 만들지 않습니다. 원문 없이 요약만 게시할 수 없습니다.
- 원문은 작성자 문장 그대로, 정리 항목·요약은 ‘운영자가 원문을 바탕으로 정리’라고 구분해 표시합니다.
- 공개 동의가 확인되지 않은 후기는 게시할 수 없습니다(서버 규칙).
- 후기 날짜는 원본 게시일을 입력하고 임의로 바꾸지 않습니다.
- 후기 구조화 데이터(Review/AggregateRating 평점)는 만들지 않습니다.
- 네이버 카페를 자동으로 긁어오는 기능은 없습니다. 운영자가 동의를 받은 글을 직접 붙여넣습니다.
