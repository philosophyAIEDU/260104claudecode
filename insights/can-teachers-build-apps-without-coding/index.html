AI 교육 칼럼 · Claude Code와 AI 수업 앱 제작

교사가 코딩을 몰라도 교육용 앱을 만들 수 있을까요?

작성자: 필로소피 AI 교육작성일 2026.11.06수정일 2026.11.06

네, 만들 수 있습니다. Claude Code나 GPT Codex 같은 AI 코딩 도구에 만들고 싶은 수업 도구를 우리말로 설명하면, AI가 코드를 작성하고 교사는 결과를 확인하며 고쳐 달라고 요청하는 방식(바이브 코딩)으로 퀴즈, 학습 도우미, 시뮬레이션 같은 간단한 웹앱을 완성할 수 있습니다. 다만 학생 개인정보를 다루거나 많은 사용자가 동시에 쓰는 앱은 보안과 운영을 따로 점검해야 합니다.

바이브 코딩은 무엇인가요?

코드를 직접 쓰는 대신, 만들고 싶은 것을 AI와 대화로 설명하며 프로그램을 완성하는 방식입니다.

교사가 할 일은 "어떤 학생이, 어떤 상황에서, 무엇을 하게 할 것인가"를 구체적으로 말하는 것입니다. 코드는 AI가 쓰고, 교사는 화면을 보며 "버튼을 더 크게", "정답을 맞히면 해설을 보여 줘"처럼 수정 요청을 반복합니다. 수업 설계 능력이 곧 앱 기획 능력이 되는 셈입니다.

어떤 앱까지 만들 수 있나요?

한 화면에서 동작하는 학습 도구부터 로그인·데이터 저장이 있는 웹앱까지 단계적으로 만들 수 있습니다.

  • 입문: 낱말 퀴즈, 개념 카드, 계산 연습기처럼 한 페이지로 끝나는 도구
  • 중급: 시뮬레이션, 학습 기록이 남는 도우미, 여러 화면이 있는 앱
  • 심화: Firebase로 로그인과 데이터 저장을 붙인 수업용 서비스

필로소피 AI 교육은 이렇게 만든 도구를 메인 페이지의 필로소피 AI 툴에 공개하고 있습니다.

처음에는 무엇부터 해야 하나요?

이번 주 수업에서 실제로 쓸 작은 도구 하나를 정하고, 대상·목표·화면을 세 줄로 적어 AI에게 건네는 것부터 시작합니다.

  1. 대상과 목표 정하기 (예: 중학교 2학년, 일차함수 기울기 이해)
  2. 학생이 보는 화면 그리기 (입력칸, 버튼, 결과)
  3. AI에게 요구사항 전달 → 결과 확인 → 수정 요청 반복
  4. GitHub에 저장하고 Netlify로 배포해 링크 공유

교육 현장에서는 어떻게 다뤘나요?

필로소피 AI 교육이 실제로 진행한 강의 가운데 이 주제와 관련된 기록입니다.

  • 전주교육청 바이브 코딩 입문 수업(2026.04.10)에서는 코딩 경험이 없는 분들도 AI와 함께 직접 도구를 만들어 볼 수 있도록 바이브 코딩의 첫 단계를 실습으로 안내했습니다.
  • 경희대학교 대학원 특강(2026.02.23)에서는 Claude와 GPT Codex를 각각 다루며, 연구와 과제에 필요한 도구를 직접 만들어 보는 과정으로 진행했습니다.

주의할 점과 한계는 무엇인가요?

  • AI가 만든 코드에도 오류가 있습니다. 학생에게 배포하기 전에 직접 여러 번 사용해 보세요.
  • 학생 이름·성적 같은 개인정보는 입력받지 않는 구조로 시작하는 것이 안전합니다.
  • 외부 AI API를 쓰는 앱은 비용과 API 키 관리가 필요합니다. 키를 화면 코드에 넣지 마세요.
